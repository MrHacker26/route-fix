# Security Policy

## Supported versions

Security fixes are applied to the latest released `v*` tag on
[`main`](https://github.com/MrHacker26/route-fix).

## Reporting a vulnerability

RouteFix can request **administrator privileges** to adjust local network
settings (Prefer IPv4 / Restore Defaults). Please treat privilege-escalation,
command-injection, or unsafe shell-handling issues as security-sensitive.

**Do not open a public issue** for security reports.

Prefer one of:

1. [GitHub private vulnerability reporting](https://github.com/MrHacker26/route-fix/security/advisories/new)
   (Settings → Code security → Enable private vulnerability reporting, if available)
2. Contact the maintainer via their GitHub profile on
   [MrHacker26](https://github.com/MrHacker26)

Include OS, RouteFix version, steps to reproduce, and impact. You should receive
an acknowledgement when practical; coordinated disclosure timelines depend on
severity and complexity.
